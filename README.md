# Omarchy Plugins

Personal plugins for the Omarchy shell.

- `fredrik.lunch` - Shows the Kanalpiren lunch menu in the bar.
- `fredrik.github-prs`
- `fredrik.ryde-nearby`
- `bylund.presenter-overlay`
- `fredrik.shield-remote` - Routes a Shield remote between this computer and native Shield TV controls, including its microphone daemon and Omarchy dictation.
